# Hi, I'm João Vitor

Software Engineer from Ponta Grossa, Paraná, Brazil, with 6+ years of experience. I build software for industry, from management platforms to logistics systems to hardware that runs on the factory floor. Addicted to dark mode.

## What I do

- **Web solutions:** Full web applications from backend to frontend, including APIs, dashboards and business platforms.
- **Industrial management software:** Systems that help industrial companies run and track their daily operations.
- **ERP solutions:** Building and customizing ERPNext, plus in-house ERP systems made for each company's processes.
- **Transport logistics:** Logistics software for industry, covering how goods are planned, moved and tracked.
- **Audit recording totems:** Hardware totems, plus the software that runs them, for recording audit activities on industrial sites.
- **Server management & deploy:** Setting up and maintaining DigitalOcean droplets, deploying with Laravel Forge or manually when needed.
- **AI development tools:** Adding AI tools to the development workflow so teams build software faster and more consistently.
- **Project leadership:** Leading development teams from planning to delivery.
